# The-Paranormal
The Paranormal é um jogo de investigação paranormal baseado em programas de tv do formato investigação paranormal/ghost hunting

## Versão atual: casa completa

A pasta histórica `paranormal-investigation-piloto-editor-jantar-20261017` mantém o nome de piloto, mas a versão atual é a **casa completa editável**. A fonte oficial é [Magrelin4ever/The-Paranormal](https://github.com/Magrelin4ever/The-Paranormal), usando Godot **4.7.2 — Linux Compatibility**.

Para começar, abra diretamente [`project.godot`](paranormal-investigation-piloto-editor-jantar-20261017/project.godot) no Godot e consulte o [guia de edição da casa inteira](paranormal-investigation-piloto-editor-jantar-20261017/GUIA_EDICAO_CASA_INTEIRA.md). A cena principal editável é [`prototype/whole_house/casa_editavel.tscn`](paranormal-investigation-piloto-editor-jantar-20261017/prototype/whole_house/casa_editavel.tscn); F5 carrega as mesmas cenas salvas, sem reconstrução procedural. Resultados, limitações e créditos estão em [`ENTREGA_CASA_INTEIRA.md`](paranormal-investigation-piloto-editor-jantar-20261017/ENTREGA_CASA_INTEIRA.md).
